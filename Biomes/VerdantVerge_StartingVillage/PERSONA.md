# Biome Persona: Verdant Verge (Starting Village Grove)

## Ecological Identity
- **Biome ID:** `verdant_verge`
- **Designation:** Homins' First Nursery & Ancient Bark Grove
- **Dominant Species:** Gentle Yubo, Placid Mektoub Calves, Lowland Torbaks
- **Canopy Baseline:** Dense Bark Canopy (100% initial integrity, 12,000 m³ timber volume)
- **Bark Physiology:** Soft fibrous outer dermis, rapid minor sapling healing, vulnerable to mass clear-cutting.

## Ecological Value & Value Matrix
- **Tranquility Threshold:** Tolerates up to 25% selective logging before signaling distress.
- **Fauna Symbiosis:** Herbivores shelter beneath lower branch nodes; tree felling eliminates grazing canopy and triggers stampede panic.
- **Mycorrhizal Connection:** Deep subterranean root filaments directly wired to Prime Roots border.

## Real-Time Stimulus Sensitivities
- `TimberHarvest`: Reduces canopy volume, generates vibrational tree-fall shocks (+0.90 to `DisplaceFaunaToPeriphery`).
- `OverloggingPressure`: When canopy falls below 65%, activates `SignalEcosystemDistress` (+0.95).
- `QuietRepose`: In absence of axes, enables `RegrowSaplings` (+0.80).
